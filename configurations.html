Les configurations

Une configuration (élément <config> du fichier config-ecrans.xml) est un profil complet de préparation d'une session DCS. Vous en créez autant que de contextes de jeu.

Ce que contient une configuration

ÉlémentDescriptionObligatoire
Clé (nom)Identifiant affiché dans la liste déroulante. Sert aussi de nom de sous-dossier dans le répertoire de configurations.Oui
Fichier optionsNom du fichier options.lua propre à cette configuration, copié dans Saved Games\Config\options.lua au lancement.Recommandé
Configuration moniteurNom du fichier de configuration moniteur de DCS, copié dans Saved Games\Config\ au lancement.Recommandé
Script d'exportFichier Export.lua à installer dans Saved Games\Scripts\ (l'ancien est sauvegardé avec un horodatage).Non
Fichiers DCS (Mainfiles)Liste de fichiers à copier depuis le sous-dossier de la configuration vers l'installation de DCS, avec options « forcer » et « sauvegarde ».Non
Lancements (LaunchCommands)Programmes/scripts compagnons à démarrer, filtrables par mode (all, 2D, VR).Non
HeliosBloc optionnel : dossier de profils, Control Center, fichier de profil.Non
ÉcransListe d'écrans (géométrie, écran principal, orientation). LITE saisie documentaire ; PRO appliquée au bureau Windows.Non
Mods associésNoms des mods à activer automatiquement quand la configuration est sélectionnée (les autres mods actifs non listés sont planifiés pour désactivation).Non

Arborescence des dossiers

Une organisation typique ressemble à ceci :

C:\Users\vous\Saved Games\Posiscreen\        <-- Répertoire de configurations (ConfigRep)
│
├─ config-ecrans.xml                         <-- fichier maître (toutes les configurations)
├─ last_run.xml                              <-- mémoire du dernier lancement
│
├─ Solo VR\                                  <-- sous-dossier = clé de la configuration
│   ├─ options.lua
│   ├─ MonitorSetup-1cam.lua
│   └─ Export.lua
│
├─ Multi 2D\
│   ├─ options.lua
│   └─ MonitorSetup-3ecrans.lua
│
├─ Cockpit Helios\
│   ├─ options.lua
│   └─ MonitorSetup-helios.lua
│
└─ Mods\                                     <-- dossier des mods (élément <mod Folder="Mods">)
    ├─ ESCA_FA18\
    │   └─ manifest.xml
    └─ CustomCockpit\
        └─ manifest.xml
Chemins relatifs

Dans l'éditeur, les noms de fichiers d'une configuration (options, moniteur, export, sources des Mainfiles) sont enregistrés relativement au sous-dossier ConfigRep\<Clé> quand le fichier choisi s'y trouve. Gardez donc les fichiers d'une configuration dans son propre sous-dossier.

Cycle de vie

  1. Création : dans l'éditeur, bouton Nouvelle configuration, vous saisissez la clé.
  2. Initialisation des dossiers : à l'enregistrement, si le sous-dossier ConfigRep\<Clé> n'existe pas, il est créé et l'application y copie l'Options.lua et le fichier de configuration moniteur actuellement en place dans DCS, renommés d'après la configuration. Les configurations déjà installées (dossier présent) ne sont pas modifiées.
  3. Personnalisation : vous ajustez le contenu du sous-dossier (préparez chaque options.lua avec les réglages DCS voulus) et complétez l'éditeur (Mainfiles, lancements, mods, Helios, écrans).
  4. Utilisation : vous sélectionnez la configuration dans la fenêtre principale et vous lancez en 2D ou VR.
  5. Renommage / suppression : possibles dans l'éditeur. Le renommage ne déplace pas le sous-dossier existant ; adaptez-le si besoin.

Le fichier last_run.xml

À chaque lancement, l'application écrit dans ConfigRep\last_run.xml : la dernière configuration utilisée, la version de DCS au moment du lancement et la date du fichier Options.lua de la configuration. Au démarrage suivant, la dernière configuration est resélectionnée automatiquement.

Réglages globaux (communs à toutes les configurations)

RéglageRôle
ConfigRepDossier contenant config-ecrans.xml, les sous-dossiers de configurations et le dossier des mods.
DcsPathDossier d'installation de DCS (contient bin\dcs.exe).
DcsSavePathDossier Saved Games de DCS (contient Config\, Scripts\, Missions\, Tracks\).
Bloc <dcs>Profils de démarrage (2D / VR), entrée de mise à jour, réglages Trk⇒miz, dossier des mods. Généré au premier enregistrement, modifiable dans le XML.
