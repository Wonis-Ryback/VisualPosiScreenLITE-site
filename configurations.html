Les profils

Un profil (élément <config> du fichier config-ecrans.xml) est un jeu complet de réglages qui prépare une session DCS. Vous en créez autant que de contextes de jeu. L'ensemble des profils, avec les réglages communs (chemins de DCS, mods, démarrages de DCS…), forme la configuration de l'application, enregistrée dans config-ecrans.xml.

Ce que contient un profil

ÉlémentDescriptionObligatoire
Clé (nom)Identifiant affiché dans la liste déroulante. Sert aussi de nom de sous-dossier dans le dossier de configuration.Oui
Fichier optionsNom du fichier options.lua propre à ce profil, copié dans Saved Games\Config\options.lua au lancement.Recommandé
Configuration moniteurNom du fichier de configuration moniteur de DCS, avec son extension .lua, copié dans Saved Games\Config\MonitorSetup\ au lancement.Recommandé
Script d'exportFichier Export.lua à installer dans Saved Games\Scripts\ (l'ancien est sauvegardé avec un horodatage).Non
Fichiers DCS (Mainfiles)Liste de fichiers à copier depuis le sous-dossier du profil vers l'installation de DCS, avec options « forcer » et « sauvegarde ».Non
Lancements (LaunchCommands)Programmes/scripts compagnons à démarrer, filtrables par mode (all, 2D, VR).Non
HeliosBloc optionnel : dossier de profils, Control Center, fichier de profil.Non
ÉcransListe d'écrans (géométrie, écran principal, orientation). LITE saisie documentaire ; PRO appliquée au bureau Windows.Non
Mods associésNoms des mods à activer automatiquement quand le profil est sélectionné (les autres mods actifs non listés sont planifiés pour désactivation).Non

Arborescence des dossiers

Une organisation typique ressemble à ceci :

C:\Users\vous\Saved Games\Posiscreen\        <-- Dossier de configuration (ConfigRep)
│
├─ config-ecrans.xml                         <-- fichier maître (tous les profils)
├─ last_run.xml                              <-- mémoire du dernier lancement
│
├─ Solo VR\                                  <-- sous-dossier = clé du profil
│   ├─ options.lua
│   ├─ MonitorSetup-1cam.lua
│   └─ Export.lua
│
├─ Multi 2D\
│   ├─ options.lua
│   └─ MonitorSetup-3ecrans.lua
│
├─ Cockpit Helios\
│   ├─ options.lua
│   └─ MonitorSetup-helios.lua
│
└─ Mods\                                     <-- dossier des mods (élément <mod Folder="Mods">)
    ├─ ESCA_FA18\
    │   └─ manifest.xml
    └─ CustomCockpit\
        └─ manifest.xml
Chemins relatifs

Dans l'éditeur, les noms de fichiers d'un profil (options, moniteur, export, sources des Mainfiles) sont enregistrés relativement au sous-dossier ConfigRep\<Clé> quand le fichier choisi s'y trouve. Gardez donc les fichiers d'un profil dans son propre sous-dossier.

Cycle de vie

  1. Création : dans l'éditeur, bouton Nouveau du groupe Profils, vous saisissez la clé.
  2. Initialisation des dossiers : à l'enregistrement, si le sous-dossier ConfigRep\<Clé> n'existe pas, il est créé et l'application y copie l'Options.lua et le fichier de configuration moniteur actuellement en place dans DCS, renommés d'après le profil. Le nom du fichier moniteur est déduit du paramètre multiMonitorSetup de l'Options.lua (DCS l'écrit sans extension : l'éditeur ajoute .lua). Les profils déjà installés (dossier présent) ne sont pas modifiés, hormis le fichier moniteur s'il manque dans leur dossier : à l'enregistrement, l'éditeur le complète sans jamais rien écraser.
  3. Personnalisation : vous ajustez le contenu du sous-dossier (préparez chaque options.lua avec les réglages DCS voulus) et complétez l'éditeur (Mainfiles, lancements, mods, Helios, écrans).
  4. Utilisation : vous sélectionnez le profil dans la fenêtre principale et vous lancez en 2D ou VR.
  5. Renommage / suppression : possibles dans l'éditeur. À l'enregistrement, le renommage d'un profil renomme aussi son sous-dossier (avec ses fichiers) ; la suppression, elle, ne supprime pas le sous-dossier.

Le fichier last_run.xml

À chaque lancement, l'application écrit dans ConfigRep\last_run.xml : le dernier profil utilisé, la version de DCS au moment du lancement et la date du fichier Options.lua du profil. Au démarrage suivant, le dernier profil est resélectionné automatiquement.

Réglages globaux (communs à tous les profils)

RéglageRôle
ConfigRepDossier contenant config-ecrans.xml, les sous-dossiers des profils et le dossier des mods.
DcsPathDossier d'installation de DCS (contient bin\dcs.exe).
DcsSavePathDossier Saved Games de DCS (contient Config\, Scripts\, Missions\, Tracks\).
Bloc <dcs>Démarrages DCS (2D / VR), entrée de mise à jour, réglages Trk⇒miz, dossier des mods. Généré au premier enregistrement, modifiable dans le XML.
