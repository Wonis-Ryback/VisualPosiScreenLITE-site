Installation & premier lancement

Prérequis

ÉlémentDétail
SystèmeWindows 10 ou Windows 11, 64 bits.
Environnement d'exécutionAucun : la version téléchargeable est autonome (le runtime .NET est inclus dans l'archive).
DCS WorldUne installation fonctionnelle (Stable ou Open Beta). L'application a besoin du dossier d'installation et du dossier Saved Games de DCS.
DroitsUn compte pouvant écrire dans le dossier Saved Games de DCS et dans le dossier de configurations que vous choisirez. Certains lancements compagnons peuvent demander les droits administrateur (paramétrable).
Accès réseauFacultatif : utilisé uniquement pour comparer la version installée de DCS à la version publiée en ligne, vérifier le pilote graphique et rechercher une nouvelle version de VisualPosiScreen LITE sur GitHub.

Mise en place

⬇ Télécharger la dernière version Windows 10/11 x64 · version autonome, sans prérequis
  1. Décompressez l'archive téléchargée dans un dossier où vous avez les droits d'écriture (par exemple C:\Outils\VisualPosiScreenLITE\). Évitez C:\Program Files\.
  2. Repérez le dossier d'installation de DCS (il contient bin\dcs.exe et bin\DCS_updater.exe).
  3. Repérez le dossier Saved Games de DCS (souvent C:\Users\<vous>\Saved Games\DCS ou …\DCS.openbeta). Il contient un sous-dossier Config.
  4. Choisissez (ou créez) un dossier de configurations qui contiendra les profils et le fichier config-ecrans.xml. Exemple : C:\Users\<vous>\Saved Games\Posiscreen\.
  5. Lancez VisualPosiScreenLITE.exe.
Mises à jour ultérieures

Une fois installée, l'application vérifie au démarrage si une nouvelle version est publiée et propose de la télécharger et de l'installer en un clic. Voir Suivi des versions.

Lancement avec un fichier de configuration précis

L'application accepte, en argument de ligne de commande, le chemin d'un fichier config-ecrans.xml : 

VisualPosiScreenLITE.exe "C:\Users\vous\Saved Games\Posiscreen\config-ecrans.xml"

Sans argument, l'application cherche config-ecrans.xml à côté de l'exécutable. Vous pouvez créer un raccourci Windows par installation de DCS (Stable / Open Beta) en indiquant le fichier voulu dans la cible du raccourci.

Assistant de premier lancement

Si aucun fichier config-ecrans.xml n'est trouvé, l'application ouvre directement l'éditeur de configuration pré-rempli avec un exemple minimal. Renseignez au minimum :

  1. Répertoire de configurations (ConfigRep) : le dossier choisi à l'étape 4 ci-dessus. C'est là que le fichier config-ecrans.xml sera enregistré.
  2. Répertoire DCS (DcsPath) : le dossier d'installation de DCS. Double-cliquez sur le champ pour parcourir les dossiers.
  3. Répertoire DCS Save (DcsSavePath) : le dossier Saved Games de DCS. Double-cliquez sur le champ pour parcourir.
  4. Vérifiez la configuration Default proposée dans la liste de gauche (nom des fichiers options.lua et configuration moniteur).
  5. Cliquez sur Valider pour contrôler la conformité, puis sur Save.

Ce que l'enregistrement du premier lancement produit

À l'enregistrement initial, l'application :

  • vérifie la présence de bin\dcs.exe et bin\DCS_updater.exe sous le répertoire DCS indiqué ; s'ils manquent, elle demande confirmation avant de continuer ;
  • génère le bloc technique <dcs> : deux profils de démarrage multi-thread (VR et 2D) pointant vers dcs.exe, une entrée de mise à jour vers DCS_updater.exe, les exclusions Trk⇒miz de base et le dossier de mods Mods ;
  • crée un sous-dossier par configuration dans le répertoire de configurations et y dépose une copie des Options.lua et fichier de configuration moniteur actuellement utilisés par DCS (quand ils existent) ;
  • écrit config-ecrans.xml dans le répertoire de configurations. Une copie .bak horodatée de l'ancien fichier est faite si un fichier existait déjà.
Bon à savoir

Après l'enregistrement, la fenêtre principale s'ouvre sur la configuration enregistrée. Vous pourrez revenir à tout moment dans l'éditeur via le lien Configurer de la barre d'outils.

Désinstallation

L'application ne s'inscrit pas dans le système. Pour la retirer, supprimez son dossier. Vos configurations (dossier ConfigRep et config-ecrans.xml) restent en place tant que vous ne les supprimez pas vous-même ; les fichiers déjà copiés dans DCS ne sont pas retirés.
