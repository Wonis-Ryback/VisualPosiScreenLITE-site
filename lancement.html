Lancer DCS World

Procédure normale

  1. Ouvrez VisualPosiScreen LITE.
  2. Choisissez la configuration dans la liste déroulante de la barre d'outils (la dernière utilisée est resélectionnée automatiquement).
  3. Vérifiez dans le cadre Mods les actions planifiées (« Activer / Désactiver »). Ajustez au besoin par clic droit.
  4. Cliquez sur VR ou sur 2D Screen.

Ce qui se passe exactement

Au clic sur VR ou 2D, dans l'ordre :

  1. Application des actions de mods planifiées pour la configuration : d'abord les désactivations, puis les activations (avec barre de progression).
  2. Copie des fichiers de configuration :
    • ConfigRep\<Clé>\<fichier options> → DcsSavePath\Config\options.lua
    • ConfigRep\<Clé>\<config moniteur> → DcsSavePath\Config\MonitorSetup\<nom>.lua, où <nom> est le nom (sans extension) référencé par multiMonitorSetup dans l'options.lua de la configuration : c'est le fichier que DCS charge.
    • « Fichiers DCS » (Mainfiles) : chaque fichier source (sous ConfigRep\<Clé>) est copié vers sa destination dans l'installation de DCS (dossiers créés au besoin), selon ses options force et backup.
    • si un script d'export est défini : sauvegarde horodatée de l'Export.lua en place, puis copie du nouveau dans DcsSavePath\Scripts\Export.lua.
  3. PRO Application de la disposition d'écrans de la configuration (position, écran principal, orientation), après mémorisation de la disposition courante. Elle précède les lancements ci-dessous pour que les programmes compagnons s'ouvrent sur le bon écran.
  4. Exécution des « Lancements » (LaunchCommands) dont le runtimeTag correspond au mode (all, ou 2D / VR selon le bouton) : chaque programme est démarré une seule fois, avec son répertoire de travail, ses paramètres et, si demandé, l'élévation de privilèges.
  5. Démarrage de Helios, si la configuration a un bloc Helios actif dont le runtimeTag correspond au mode : Helios Control Center est lancé avec le profil indiqué. Control Center n'accepte qu'une instance : s'il tourne déjà, il reçoit simplement le profil à charger.
  6. Démarrage de DCS avec le profil correspondant (le chemin de dcs.exe est vérifié avant toute action : si DCS a été déplacé, un message l'indique et rien n'est modifié) :
    • VR : profil multi-thread VR (paramètres type --force_enable_VR --force_OpenXR).
    • 2D Screen : profil multi-thread 2D (paramètre type --force_no_VR).
  7. Écriture de last_run.xml : configuration, version de DCS et date du fichier Options.lua de la configuration.
  8. Fermeture de VisualPosiScreen LITE.
En cas d'erreur pendant la préparation

Si une étape échoue (fichier source introuvable, programme compagnon ou Helios qui ne démarre pas…), les étapes suivantes sont tout de même exécutées puis une boîte de dialogue vous propose de continuer ou d'abandonner le démarrage de DCS. Le détail figure dans le journal. Si DCS lui-même ne peut pas démarrer (chemin introuvable, droits administrateur refusés), un message explique pourquoi et l'application reste ouverte pour que vous puissiez corriger et réessayer.

Les profils 2D / VR

Ils proviennent du bloc <dcs> (éléments <build> avec tag="2D" / tag="VR" et threading="MT"). Générés au premier enregistrement, ils sont modifiables dans config-ecrans.xml — par exemple pour changer les arguments passés à dcs.exe.

Tester sans lancer DCS

  • Double-clic sur une ligne du cadre Mainfiles : exécute uniquement cette copie.
  • Double-clic sur une ligne du cadre LaunchFiles : lance uniquement ce programme.
  • Bouton Comparer : vérifie que l'options.lua de la configuration et celui de DCS sont cohérents avant de jouer (voir Outils intégrés).

Après la session

  • Relancez VisualPosiScreen LITE si vous voulez changer de configuration ou d'état de mods.
  • Utilisez Comparer pour reporter dans la configuration les réglages modifiés en jeu (si vous avez ajusté des options depuis DCS).
  • Après une mise à jour de DCS ou du pilote graphique, pensez à Effacer FXO.
  • PRO la disposition d'écrans d'origine peut être restaurée automatiquement.
Un lancement compagnon ne démarre pas

Vérifiez le chemin de l'exécutable, le répertoire de travail et le runtimeTag (un programme en VR ne se lance pas au démarrage 2D). Les erreurs sont consignées dans le journal. Pour Helios, vérifiez aussi que Control Center et le fichier de profil existent.
