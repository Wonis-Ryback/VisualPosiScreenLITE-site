PRO LED Virpil selon l'avion

VirpilLeds est livré avec VisualPosiScreen PRO, dans le même dossier (VirpilLeds.exe). Il règle les LED de vos périphériques Virpil (joysticks, panneaux) selon l'avion que vous pilotez dans DCS, et peut les faire réagir à ce qui se passe dans le cockpit : par exemple, faire clignoter une LED en jaune quand le Master Caution s'allume.

Ce qu'il faut

DCS-BIOS installé dans DCS (dossier Scripts\DCS-BIOS de vos Parties enregistrées) : c'est lui qui indique l'avion et l'état du cockpit. Prenez une version récente pour les modules récents (le C-130J demande DCS-BIOS 0.11.7 ou plus).

VirpilLeds ne modifie ni le firmware ni vos profils VPC Configurator. Une LED sans règle garde le réglage de VPC Configurator, et tout revient à ce réglage quand DCS est fermé.

La fenêtre VirpilLeds

Ouvrez VirpilLeds.exe dans le dossier de VisualPosiScreen PRO, ou double-cliquez sur son icône dans la zone de notification quand le suivi DCS tourne. La fenêtre a trois parties :

  • à gauche : vos périphériques Virpil (avec le nombre de LED placées, ou ce qu'il reste à faire), puis Quand : les situations pour lesquelles vous réglez les LED ;
  • au centre : l'image du périphérique, avec une pastille par LED ;
  • à droite : le réglage de la LED choisie.

Tant que la case Voir sur le Virpil pendant le réglage est cochée, chaque réglage s'affiche aussitôt sur le périphérique. En fermant la fenêtre, les LED essayées reviennent au réglage de VPC Configurator.

Première fois : relever et placer les LED

Les LED ne sont pas les mêmes d'un modèle de Virpil à l'autre, et toutes ne répondent pas. Il faut donc, une fois par périphérique :

  1. Relever les LED : Avancé…, choisissez le périphérique et une carte, puis Balayer la carte. Chaque LED s'allume en blanc à son tour ; répondez Elle s'allume, Rien ou Autre chose. Seules les LED qui s'allument seront proposées ensuite.
  2. Placer les LED sur l'image : dans la fenêtre principale, Placer les LED…. Chaque LED relevée s'allume ; cliquez sur l'image à l'endroit où vous la voyez. Pour une zone éclairée (marquages d'un manche, couronne), tracez un rectangle. Donnez-lui un nom (RST, Train…) : c'est ce nom qui apparaît ensuite.
L'image du périphérique

Si vous avez déjà mis une image pour ce périphérique dans Commandes des joysticks, VirpilLeds la reprend. Sinon, Choisir une autre image… pendant le placement accepte n'importe quelle image (PNG, JPG).

Quand : les situations

  • Hors vol : DCS est ouvert, mais vous n'êtes pas dans un avion. Ce réglage est à part : il ne reprend rien des autres.
  • Par défaut : tous les avions.
  • Avion à réaction, Avion à hélice, Hélicoptère, Non classé : une catégorie reprend le réglage Par défaut, sauf pour les LED que vous y réglez.
  • Un avion (AH-64D_BLK_II, F-16C_50…) : reprend sa catégorie, sauf pour les LED que vous y réglez. Ajouter un avion… propose les avions connus de DCS-BIOS avec leur catégorie ; les avions pilotés pendant le suivi s'ajoutent tout seuls. Clic droit sur un avion : Déplacer vers une autre catégorie, ou Retirer de la liste.

Sur l'image, une pastille pleine est réglée à ce niveau, un anneau reprend le niveau du dessus, un anneau en pointillé est laissé à VPC Configurator. Ctrl+clic choisit plusieurs LED à la fois : le réglage s'applique à toutes.

Régler une LED

Normalement : ce que fait la LED dans cette situation.

  • Comme « … » : reprend le niveau du dessus (pour Par défaut et Hors vol : pas de règle, réglage de VPC Configurator) ;
  • Laisser à VPC : réglage de VPC Configurator, même si le niveau du dessus a une couleur ;
  • Couleur : une des 64 couleurs des LED Virpil, fixe ou clignotante (lent, normal, rapide). En clignotement, la LED alterne entre la couleur 1 et la couleur 2 (éteinte par défaut).

Sauf si : réagir au cockpit

Une exception change la LED quand une condition du cockpit est vraie : si le Master Caution est allumé, la LED clignote en jaune. Ajouter une exception… ouvre une fenêtre avec, à droite, la liste des voyants et commandes de l'avion fournis par DCS-BIOS (recherche par nom) : un clic remplit la condition. Pour un voyant, la valeur est allumé ou éteint ; pour un interrupteur, sa position.

  • Les conditions d'une exception sont reliées par et. Pour un ou, ajoutez une deuxième exception.
  • Les exceptions sont lues dans l'ordre : la première vraie l'emporte. Si aucune n'est vraie, c'est le réglage Normalement qui s'applique.
  • Clic sur une exception : la modifier. Clic droit : la monter, la descendre ou la supprimer.
  • Au niveau d'une catégorie ou de Par défaut, seules les données communes à tous les avions sont proposées. Les voyants propres à un avion se règlent au niveau de cet avion.
  • Si DCS tourne pendant le réglage, la fenêtre montre la valeur actuelle de chaque condition, et une exception vraie est marquée vraie en ce moment.

Suivre DCS pendant le vol

Le suivi DCS fait le travail pendant le vol : il reconnaît l'avion, applique vos réglages et suit les exceptions. Il tourne en arrière-plan, avec une icône dans la zone de notification (état, ouverture de la fenêtre, pause, journal, quitter). Pour le lancer avec DCS, ajoutez-le à votre profil :

  1. Dans l'éditeur de configuration, onglet Lancements, cliquez sur Catalogue….
  2. Choisissez VirpilLeds (LED Virpil selon l'avion) : la commande et le paramètre --run sont remplis.

Un second lancement ne fait rien : le suivi tourne une seule fois. Vous pouvez aussi le lancer depuis la fenêtre (Démarrer le suivi DCS) ou à chaque ouverture de session (Options…). Pendant que la fenêtre VirpilLeds est ouverte, le suivi attend et reprend à sa fermeture. DCS fermé ou hors mission : toutes les LED reviennent au réglage de VPC Configurator.

Options

  • Éteindre les LED quand Windows s'arrête, redémarre ou ferme la session : installe un petit service Windows (une confirmation Windows est demandée). Les LED reprennent le réglage de VPC Configurator au démarrage suivant.
  • Démarrer le suivi DCS à l'ouverture de session : inutile si votre profil le lance déjà.

Lors d'une mise à jour de VisualPosiScreen PRO, VirpilLeds est fermé le temps de remplacer ses fichiers, puis le suivi est relancé s'il tournait. Journal du suivi : %LOCALAPPDATA%\VirpilLeds\suivi-dcs.txt.
