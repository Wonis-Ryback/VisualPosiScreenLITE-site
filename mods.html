Gestion des mods

L'application gère les mods « manuels » de DCS : des ensembles de fichiers à copier dans l'installation de DCS et/ou dans le dossier Saved Games, que l'on veut pouvoir activer ou retirer proprement, avec sauvegarde.

Où sont rangés les mods

Le dossier des mods est déclaré une fois dans le bloc <dcs> (élément <mod Folder="Mods"/>), relatif au dossier de configuration. Chaque mod est un sous-dossier contenant un fichier manifest.xml : 

ConfigRep\Mods\
├─ ESCA_FA18\
│   ├─ manifest.xml
│   ├─ <fichiers du mod pour l'installation DCS>
│   └─ <fichiers du mod pour Saved Games>
└─ CustomCockpit\
    └─ manifest.xml

Contenu du manifest.xml

ÉlémentRôle
nameNom du mod (doit correspondre au nom du dossier).
versionVersion utilisée du mod, affichée dans la colonne Version de la liste des mods et dans l'éditeur de mod.
status/@enabledÉtat déployé (vrai) ou non (faux). Mis à jour par l'application.
descriptionTexte affiché dans la liste des mods.
rootSous-dossier du mod à copier vers l'installation de DCS. Attribut backup : sauvegarder les fichiers écrasés.
saveGamesSous-dossier du mod à copier vers Saved Games. Attribut backup également.
incompatibleModsListe de noms de mods incompatibles avec celui-ci.
versionsVersions installées du mod, chacune avec ses dossiers : <version num="4" root="versions\4\root" saveGames="versions\4\savegames"/>. Absent tant que le mod n'a qu'une version. Voir Versions d'un mod.

Le cadre « Mods » de la fenêtre principale

  • Chaque mod détecté apparaît avec sa version, sa description et une pastille : verte = déployé, rouge = non déployé.
  • Colonne Version : quand un mod a plusieurs versions installées (la cellule affiche par exemple 3 ▾), un clic sur la cellule ouvre la liste de ses versions pour choisir celle à utiliser. Voir Versions d'un mod.
  • Clic droit sur un mod :
    • Enable / Disable : déploie ou retire le mod immédiatement (barre de progression).
    • Ajouter/Supprimer de la liste des mods à activer ou à désactiver : modifie les actions planifiées pour le profil courant (appliquées au lancement). Ajouter un mod à activer planifie aussi la désactivation des mods actifs qui lui sont incompatibles.
  • Double-clic sur un mod : bascule son état immédiatement (déployé → retiré, retiré → déployé), avec la gestion des incompatibilités ci-dessous.
  • Modifier : ouvre l'éditeur de mod.
  • Supprimer : désactive le mod, retire ses sauvegardes, l'enlève de la liste et enregistre. — irréversible, une confirmation est demandée.
  • La zone de texte de droite récapitule les actions planifiées : « Activer : X » (vert), « Désactiver : Y » (rouge), et, en orange, les lignes « Attention : » qui expliquent une désactivation ou un mod écarté à cause d'une incompatibilité.
Activation « immédiate » ou « planifiée » ?

Enable/Disable et le double-clic agissent tout de suite sur les fichiers. Les listes « à activer / à désactiver » ne sont exécutées qu'au moment où vous cliquez sur VR ou 2D — d'abord les désactivations, puis les activations.

Ajouter (installer) un mod

Le bouton Ajouter crée un mod dans le dossier des mods. Vous indiquez son nom, sa version, sa description, la source de ses fichiers Root (installation DCS) et Saved Games — un dossier, ou un dossier à l'intérieur d'une archive ZIP —, les cases de sauvegarde, les mods incompatibles et les profils auxquels l'associer.

La copie d'un mod peut porter sur plusieurs centaines de Mo. Elle se fait en tâche de fond, sous une fenêtre de progression qui affiche l'action en cours : le fichier copié, les octets copiés sur le total, le pourcentage, la durée et la vitesse. Le bouton Annuler interrompt l'installation, même au milieu d'un gros fichier, et supprime ce qui avait déjà été copié. Une notification de fin indique le nombre de fichiers, la taille et la durée. Le mod est installé désactivé : activez-le ensuite depuis la liste. Son déploiement (et son retrait) affiche la même fenêtre de progression.

Que fait le déploiement d'un mod

  1. Le sous-dossier root du mod est copié vers le répertoire d'installation de DCS. Si backup est actif, chaque fichier écrasé est d'abord copié dans un dossier <root>.BAK du mod.
  2. Le sous-dossier saveGames du mod est copié vers Saved Games, avec la même logique de sauvegarde vers <saveGames>.BAK.
  3. L'état enabled du mod est inversé et le manifest.xml est réécrit.

Que fait le retrait d'un mod

  1. Les fichiers du mod présents aux emplacements de destination sont supprimés.
  2. Si une sauvegarde .BAK existe, les fichiers d'origine sont restaurés.
  3. Les dossiers devenus vides sont supprimés.
  4. L'état enabled repasse à « non » et le manifest.xml est réécrit.

Éditeur de mod

Ouvert par Modifier ou par le menu, il permet de régler :

  • Répertoire Root et Répertoire Partie enregistrée (SaveGames), avec sélecteur de dossier — les chemins sont mémorisés relativement au dossier du mod.
  • Cases sauvegarde pour Root et pour SaveGames.
  • Description et Version (numéro de la version utilisée ; il ne peut pas reprendre celui d'une autre version du mod).
  • Le bouton Versions du mod… : ajout et suppression de versions (voir Versions d'un mod).
  • Incompatibilités : liste à cocher des autres mods incompatibles.
  • Associer ce mod aux profils : cocher les profils pour lesquels ce mod doit être actif (met à jour la liste « Mods associés » de chaque profil).

À la validation, le manifest.xml du mod et le fichier config-ecrans.xml sont réécrits.

Remplacer les fichiers d'un mod (mise à jour)

Quand un mod sort en nouvelle version, le bouton Remplacer les fichiers du mod… de l'éditeur de mod efface le contenu actuel de son dossier root et/ou saveGames et le remplace par de nouveaux fichiers.

  1. Pour Root et/ou Saved Games, choisissez la nouvelle source : un dossier, ou un dossier à l'intérieur d'une archive ZIP (comme à la création d'un mod). Une ligne laissée vide n'est pas touchée. Vous pouvez aussi saisir la nouvelle version du mod.
  2. Préparer l'aperçu : la nouvelle version est préparée dans un dossier temporaire puis comparée à l'existante. L'aperçu liste les fichiers ajoutés (+), modifiés (~) et supprimés (−, absents de la nouvelle version). Rien n'est encore modifié.
  3. Remplacer les fichiers puis confirmation : les dossiers sont échangés. L'ancienne version n'est supprimée qu'une fois le remplacement réussi ; en cas d'échec, elle est remise en place.
Mod activé ?

Il est d'abord retiré de DCS et de Saved Games (avec restauration des fichiers d'origine si la sauvegarde est cochée), ses fichiers sont remplacés, puis il est redéployé. Ainsi, les fichiers absents de la nouvelle version ne restent pas dans DCS. DCS doit être fermé ; l'application le vérifie.

  • Seuls les dossiers root et saveGames du mod sont concernés : le manifest.xml et les dossiers de sauvegarde .BAK ne sont pas touchés.
  • Une source qui ne contient aucun fichier est refusée, ainsi qu'une archive contenant des chemins qui sortiraient du dossier du mod.
  • L'opération est immédiate : le bouton Annuler de l'éditeur ne la défait pas.
  • Si le mod a plusieurs versions, seuls les fichiers de la version utilisée sont remplacés. Pour garder l'ancienne version à côté de la nouvelle, ajoutez plutôt une version (ci-dessous).

Versions d'un mod

Un mod peut garder plusieurs versions installées côte à côte (par exemple ESCA F18 en version 3 et en version 4), et passer de l'une à l'autre sans réinstaller ses fichiers. Chaque version a ses propres fichiers Root et Saved Games.

Ajouter une version

  1. Ouvrez l'éditeur du mod (Modifier), puis Versions du mod…. La fenêtre liste les versions installées, leur taille et celle qui est utilisée (en gras).
  2. Ajouter une version… : saisissez son numéro (par exemple 4), puis la source de ses fichiers Root et/ou Saved Games : un dossier, ou un dossier à l'intérieur d'une archive ZIP. Une ligne laissée vide reprend les fichiers de la version utilisée actuellement (pratique quand une nouvelle version ne change que la partie Saved Games, par exemple).
  3. Ajouter la version : les fichiers sont copiés (fenêtre de progression, avec Annuler) dans versions\<numéro>\ du dossier du mod. Les autres versions ne sont pas touchées, et la version utilisée ne change pas.
ConfigRep\Mods\ESCA_FA18\
├─ manifest.xml
├─ root\              ← version d'origine (3)
├─ savegames\
└─ versions\
    └─ 4\
        ├─ root\
        └─ savegames\

Choisir la version à utiliser

Dans la fenêtre principale, cliquez sur la cellule de la colonne Version du mod et choisissez la version dans la liste.

  • Mod désactivé : la version choisie est simplement mémorisée ; c'est elle qui sera déployée à la prochaine activation (immédiate ou au lancement).
  • Mod activé : après confirmation, l'ancienne version est retirée de DCS et de Saved Games (avec restauration des fichiers d'origine si la sauvegarde est cochée), puis la nouvelle est déployée. DCS doit être fermé ; l'application le vérifie. Si le retrait échoue, la version ne change pas.
  • Le choix vaut pour tous les profils : les profils associent un mod, pas une version.

Supprimer une version

Dans Versions du mod…, sélectionnez la version puis Supprimer la version… : ses fichiers sont supprimés définitivement après confirmation. La version utilisée ne peut pas être supprimée : choisissez d'abord une autre version.

Plusieurs installations sur le même dossier de mods

Une ancienne version de l'application ne connaît pas les versions de mods : si elle réenregistre le manifest.xml d'un mod, la liste versions est perdue (les dossiers restent sur le disque). Mettez à jour toutes les installations qui partagent le même dossier de mods.

Incompatibilités

Deux mods sont incompatibles dès que l'un des deux le déclare (dans l'éditeur de mod).

  • Activation immédiate (Enable, double-clic) : si le mod est incompatible avec des mods actifs, l'application le signale et propose de les désactiver d'abord. Le mod n'est activé que si ces désactivations ont réussi ; les pastilles de tous les mods sont remises à jour.
  • Actions planifiées : si un mod à activer (associé au profil, ou ajouté par le menu) est incompatible avec un mod actif, la désactivation de ce dernier est planifiée. Si deux mods à activer sont incompatibles entre eux, un seul est retenu : le dernier que vous avez ajouté à la main, sinon le premier de la liste du profil.
  • Au lancement, avant chaque activation, les mods actifs incompatibles sont désactivés, quoi qu'ait prévu la liste.

Mise à jour de DCS et mods

Avant une mise à jour de DCS, il est recommandé de désactiver les mods qui touchent l'installation, pour éviter que le programme de mise à jour ne détecte des fichiers modifiés. Réactivez-les ensuite via le profil.
