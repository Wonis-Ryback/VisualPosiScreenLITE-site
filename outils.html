Outils intégrés

Suivi de la version de DCS

Dans le cadre Version DCS de la fenêtre principale :

  • Version installée : lue dans bin\dcs.exe.
  • Version en ligne : récupérée sur le serveur de mise à jour de DCS. « À jour » si elle correspond, sinon le numéro disponible s'affiche en rouge et le bouton M.a.J devient actif.
  • M.a.J : lance DCS_updater.exe (avec élévation). Les mods actifs sont retirés avant, puis l'application propose de les réactiver. Voir Mettre à jour DCS.
  • Réparer : lance DCS_updater.exe repair, qui vérifie les fichiers de DCS et retélécharge ceux qui sont abîmés ou manquants. Les mods actifs sont retirés avant, puis l'application propose de les réactiver. Voir Réparer DCS.
  • Notes de version : ouvre le changelog officiel dans le navigateur.
  • Effacer FXO : vide Saved Games\fxo et Saved Games\metashaders2 (cache de shaders). À faire après une mise à jour de DCS ou de pilote graphique si vous constatez des artefacts.

Mettre à jour DCS

Le bouton M.a.J n'est actif que si la version en ligne diffère de la version installée. Il suit exactement le même parcours que Réparer : confirmation avec la liste des mods actifs, retrait de ces mods, lancement de DCS_updater.exe avec élévation (l'application attend qu'il ait terminé), puis un seul « oui » pour réactiver l'ensemble des mods retirés. Elle refuse de démarrer si DCS.exe ou DCS_updater.exe tourne déjà.

Quand DCS_updater.exe se termine, l'application relit la version installée et la compare de nouveau à la version en ligne : si DCS est à jour, la ligne Online affiche « À jour » et M.a.J s'éteint. Comme il est lancé sans argument, DCS_updater.exe ouvre sa propre fenêtre : c'est là que vous suivez le téléchargement.

Réparer DCS

Le bouton Réparer du cadre Version DCS lance DCS_updater.exe repair : DCS compare ses fichiers à ceux de la version officielle et retélécharge ceux qui sont modifiés, abîmés ou manquants. Cela peut être long. À utiliser quand DCS ne démarre plus ou plante après une mise à jour ratée, une coupure pendant un téléchargement ou l'installation d'un mod.

  1. L'application demande confirmation. Si des mods sont actifs, elle en affiche la liste : ils vont être retirés de DCS avant la réparation (sinon leurs fichiers seraient pris pour des fichiers abîmés et écrasés ou signalés).
  2. Elle refuse de continuer si DCS.exe ou DCS_updater.exe tourne déjà : fermez-les d'abord.
  3. DCS_updater.exe est lancé avec élévation de privilèges (une demande Windows apparaît). Il ouvre sa propre fenêtre ; l'application attend qu'il ait terminé et affiche une petite fenêtre d'attente.
  4. À la fin, l'application demande un seul « oui » pour réactiver l'ensemble des mods qui étaient actifs. Répondre « non » les laisse désactivés ; vous pourrez les réactiver depuis la liste des mods.

Si vous refusez l'élévation ou si la réparation ne peut pas démarrer, DCS n'est pas modifié, et la réactivation des mods est quand même proposée.

Helios et shaders (mise à jour comme réparation)

Après une mise à jour comme après une réparation, si un profil utilise Helios, l'application rappelle qu'il faut ré-appliquer les patchs avec Helios Profile Editor (elle propose de l'ouvrir). Si la configuration demande d'effacer les shaders (attribut removeshadder de <update>), ils sont aussi effacés.

Informations carte graphique

  • Détection automatique du fabricant (NVIDIA / AMD / Intel), modèle, VRAM, version de pilote.
  • NVIDIA : comparaison automatique avec la dernière version connue ; message « à jour » (vert) ou « nouveau pilote disponible » (orange) avec lien.
  • AMD : comparaison automatique avec la dernière version d'AMD Software : Adrenalin Edition, d'après ses notes de version (le lien mène à la page de la version) ; une version « facultative » est signalée comme telle. Le résultat est conservé 12 heures pour ne pas solliciter le site d'AMD à chaque démarrage. Si la vérification échoue (site inaccessible, carte trop ancienne pour les pilotes récents), le lien vers la page pilote d'AMD est proposé.
  • Intel : lien direct vers la page pilote du fabricant.
  • Les liens s'ouvrent dans le navigateur par défaut d'un simple clic.

Comparaison d'options.lua

Bouton Comparer de la barre d'outils. Compare :

  • à gauche : l'Options.lua du profil actif (sélectionné dans la liste), dans le dossier du profil : ConfigRep\<profil>\Options.lua (ou le fichier indiqué par le profil) ;
  • à droite : DcsSavePath\Config\Options.lua (celui utilisé par DCS).

À l'ouverture de l'application et à chaque changement de profil, cette comparaison est faite en arrière-plan : si les deux fichiers diffèrent (réglages modifiés dans DCS), le bouton Comparer passe en rouge. Aucune fenêtre ne s'ouvre ; c'est vous qui décidez de comparer.

La comparaison est structurée (analyse de la table Lua, pas une simple différence de texte) : elle liste les clés absentes d'un côté ou de l'autre, les types différents et les valeurs différentes. Si les deux fichiers sont équivalents, un message le confirme. Sinon, une fenêtre affiche les écarts et permet de reporter le fichier de DCS vers celui du profil.

Usage typique

Vous avez peaufiné des réglages graphiques dans DCS pendant une session. De retour dans VisualPosiScreen LITE, Comparer vous montre ce qui a changé et vous propose de sauvegarder ces réglages dans la configuration pour les conserver.

Trk⇒miz — conversion de tracks en missions

Bouton Trk⇒miz de la barre d'outils. Un fichier track .trk (un replay enregistré) est en réalité une archive contenant la mission plus des données de replay. Cet outil recrée un .miz jouable en retirant les éléments de replay.

Disposition de la fenêtre

  • Liste des tracks : fichiers de Saved Games\Tracks\Multiplayer, du plus récent au plus ancien, avec cases à cocher.
  • Arborescence des missions : le dossier Missions de DCS ; sélectionnez le nœud pour définir le dossier cible.
  • Options :
    • Garder l'horodatage : conserve (ou retire) le suffixe date/heure dans le nom généré.
    • Prefill : propose automatiquement le nom du fichier mission à partir du track sélectionné.
    • Supprimer le track après conversion.
  • File d'attente : liste des conversions à effectuer (colonnes horodatage, suppression, source, cible).

Deux modes de conversion

SituationComportement du bouton « Convertir »
File d'attente videConversion unique : le track coché/sélectionné est converti vers le dossier cible et le nom de mission saisis dans les champs.
File d'attente remplieConversion par lot : chaque ligne de la file est convertie ; les champs de saisie sont ignorés. Un bilan indique le nombre de fichiers convertis et d'échecs.

Mission déjà présente

Avant d'écrire une mission, l'outil vérifie si elle existe déjà dans le dossier cible. Si c'est le cas, une fenêtre affiche la date, l'heure et la taille de la mission présente et du track à convertir, et demande : Remplacer, Ignorer (la mission présente est conservée) ou Annuler. Avec plusieurs tracks dans la file d'attente, Remplacer tout et Ignorer tout évitent de répondre à chaque fois. Un track ignoré n'est pas supprimé, même si l'option de suppression est cochée. La conversion se fait dans un fichier temporaire : en cas d'échec, la mission existante reste intacte.

Éléments exclus

Lors de la conversion, les entrées correspondant aux exclusions Trk⇒miz du bloc <dcs> sont retirées de l'archive (par défaut : track_data, track, Config). Vous pouvez ajuster cette liste dans config-ecrans.xml.

Sauvegardez vos tracks d'origine

L'option Supprimer le track après conversion efface le fichier .trk source. Ne l'activez que si vous n'en avez plus besoin.

Journal d'activité

L'icône « bug » de la barre d'outils ouvre la fenêtre de journal. Elle recense les opérations effectuées (copies, déploiements de mods, lancements, mises à jour) et les erreurs, avec leur origine. C'est la première chose à consulter quand une action ne produit pas l'effet attendu.

Contacter le support

Le bouton Support… de la barre d'outils (ou Contacter le support dans la fenêtre de journal) prépare une demande de support avec ce qu'il faut pour comprendre le problème.

  • Indiquez ce que vous essayiez de faire quand le problème est survenu.
  • Choisissez ce qui accompagne votre demande : les informations système (versions de l'application, de Windows et de .NET, carte graphique et pilote, taille des écrans) et le journal, avec le niveau minimum voulu (DEBUG, INFO, WARN, ERROR) et le nombre de lignes.
  • L'aperçu montre exactement le message : le texte qui s'ouvre dans votre messagerie, et le rapport complet enregistré dans un fichier à joindre.
  • Votre nom d'utilisateur Windows, le nom du PC et le dossier de votre profil sont automatiquement remplacés (le nombre de remplacements est indiqué). Les noms de mods, de configurations et les chemins que vous avez choisis ne sont pas modifiés : relisez l'aperçu.
Rien n'est envoyé par l'application

« Ouvrir dans ma messagerie » ouvre votre logiciel de messagerie avec le message pré-rempli : vous le relisez, joignez le fichier du rapport (son dossier s'ouvre) puis vous l'envoyez vous-même. Sans logiciel de messagerie, « Copier le rapport complet » le place dans le presse-papiers pour le coller dans un message.
