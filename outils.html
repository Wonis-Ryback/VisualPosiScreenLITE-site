Outils intégrés

Suivi de la version de DCS

Dans le cadre Version DCS de la fenêtre principale :

  • Version installée : lue dans bin\dcs.exe.
  • Version en ligne : récupérée sur le serveur de mise à jour de DCS. « À jour » si elle correspond, sinon le numéro disponible s'affiche en rouge et le bouton M.a.J devient actif.
  • M.a.J : lance DCS_updater.exe (avec élévation). Désactivez d'abord les mods qui touchent l'installation.
  • Notes de version : ouvre le changelog officiel dans le navigateur.
  • Effacer FXO : vide Saved Games\fxo et Saved Games\metashaders2 (cache de shaders). À faire après une mise à jour de DCS ou de pilote graphique si vous constatez des artefacts.

Informations carte graphique

  • Détection automatique du fabricant (NVIDIA / AMD / Intel), modèle, VRAM, version de pilote.
  • NVIDIA : comparaison automatique avec la dernière version connue ; message « à jour » (vert) ou « nouveau pilote disponible » (orange) avec lien.
  • AMD / Intel : lien direct vers la page pilote du fabricant.
  • Les liens s'ouvrent dans le navigateur par défaut d'un simple clic.

Comparaison d'options.lua

Bouton Comparer de la barre d'outils. Compare :

  • à gauche : ConfigRep\<dernière config>\Options.lua ;
  • à droite : DcsSavePath\Config\Options.lua (celui utilisé par DCS).

La comparaison est structurée (analyse de la table Lua, pas une simple différence de texte) : elle liste les clés absentes d'un côté ou de l'autre, les types différents et les valeurs différentes. Si les deux fichiers sont équivalents, un message le confirme. Sinon, une fenêtre affiche les écarts et permet de reporter le fichier de DCS vers celui de la configuration.

Usage typique

Vous avez peaufiné des réglages graphiques dans DCS pendant une session. De retour dans VisualPosiScreen LITE, Comparer vous montre ce qui a changé et vous propose de sauvegarder ces réglages dans la configuration pour les conserver.

Trk⇒miz — conversion de tracks en missions

Bouton Trk⇒miz de la barre d'outils. Un fichier track .trk (un replay enregistré) est en réalité une archive contenant la mission plus des données de replay. Cet outil recrée un .miz jouable en retirant les éléments de replay.

Disposition de la fenêtre

  • Liste des tracks : fichiers de Saved Games\Tracks\Multiplayer, du plus récent au plus ancien, avec cases à cocher.
  • Arborescence des missions : le dossier Missions de DCS ; sélectionnez le nœud pour définir le dossier cible.
  • Options :
    • Garder l'horodatage : conserve (ou retire) le suffixe date/heure dans le nom généré.
    • Prefill : propose automatiquement le nom du fichier mission à partir du track sélectionné.
    • Supprimer le track après conversion.
  • File d'attente : liste des conversions à effectuer (colonnes horodatage, suppression, source, cible).

Deux modes de conversion

SituationComportement du bouton « Convertir »
File d'attente videConversion unique : le track coché/sélectionné est converti vers le dossier cible et le nom de mission saisis dans les champs.
File d'attente remplieConversion par lot : chaque ligne de la file est convertie ; les champs de saisie sont ignorés. Un bilan indique le nombre de fichiers convertis et d'échecs.

Éléments exclus

Lors de la conversion, les entrées correspondant aux exclusions Trk⇒miz du bloc <dcs> sont retirées de l'archive (par défaut : Scripts, track_data, track, Config). Vous pouvez ajuster cette liste dans config-ecrans.xml.

Sauvegardez vos tracks d'origine

L'option Supprimer le track après conversion efface le fichier .trk source. Ne l'activez que si vous n'en avez plus besoin.

Journal d'activité

L'icône « bug » de la barre d'outils ouvre la fenêtre de journal. Elle recense les opérations effectuées (copies, déploiements de mods, lancements, mises à jour) et les erreurs, avec leur origine. C'est la première chose à consulter quand une action ne produit pas l'effet attendu.
