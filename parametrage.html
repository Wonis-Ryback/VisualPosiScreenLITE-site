L'éditeur de configuration

On y accède par le lien Configurer de la barre d'outils (ou automatiquement au premier lancement). L'éditeur travaille sur une copie du modèle : rien n'est écrit tant que vous ne cliquez pas sur Save. La fenêtre est organisée en maître / détail : la liste des profils à gauche, le panneau d'édition à droite.

Réglages globaux

ChampComment le renseigner
Dossier de configurationDossier qui recevra config-ecrans.xml. En premier lancement, il est pré-rempli avec le dossier de l'exécutable ou vos Documents.
Répertoire DCSDouble-cliquez le champ pour ouvrir un sélecteur de dossier. Pointez le dossier d'installation de DCS.
Répertoire DCS SaveDouble-cliquez le champ pour parcourir. Pointez le dossier Saved Games de DCS.

Liste des profils

  • Nouveau : demande un nom (clé unique) et crée un profil vide.
  • Renommer : change la clé. À l'enregistrement, le sous-dossier ConfigRep\<ancien nom> est renommé avec ses fichiers (le dernier profil lancé suit aussi). Si un dossier du nouveau nom existe déjà, l'enregistrement est refusé et rien n'est modifié ; si le fichier de configuration ne peut pas être écrit, les dossiers reprennent leur ancien nom. Le nom sert aussi de nom de dossier : les caractères \ / : * ? " < > | sont refusés.
  • Supprimer : retire le profil du modèle après confirmation (ne supprime pas le sous-dossier sur le disque).
  • Le passage d'un profil à l'autre enregistre automatiquement les modifications en cours sur le profil que vous quittez.

Panneau d'édition d'un profil

Général

  • Clé : en lecture seule (utilisez Renommer).
  • Fichier options, Configuration moniteur, Script d'export : bouton Parcourir. Si le fichier choisi est sous ConfigRep\<Clé>, seul son nom relatif est mémorisé.

Grille « Fichiers DCS » (Mainfiles)

Fichiers à copier depuis ConfigRep\<Clé> (le dossier du profil) vers l'installation de DCS.

ColonneSignification
SourceNom d'un fichier du dossier du profil, ou chemin complet d'un fichier à copier. Bouton … pour parcourir.
DestinationChemin (relatif au répertoire DCS) où copier le fichier, avec son vrai nom. Bouton … pour parcourir.
ForceÉcrase le fichier de destination s'il existe. Sans Force, un fichier déjà présent est conservé.
BackupFait une copie horodatée (<nom>_<date>.bak, à côté du fichier) avant d'écraser.

Boutons Ajouter / Supprimer / Monter / Descendre pour gérer l'ordre.

Un même nom de fichier à plusieurs endroits de DCS

Un fichier comme ControlsIndicator_page.lua existe dans le dossier de chaque module de DCS. Quand vous choisissez un fichier par son chemin complet, l'enregistrement du profil le copie dans le dossier du profil sous un nom unique (ControlsIndicator_page.<empreinte>.lua, calculée à partir de la destination) et remplace la Source par ce nom. Plusieurs fichiers de même nom, destinés à des modules différents, coexistent ainsi dans le profil ; au lancement, chacun est copié dans DCS sous son vrai nom, à l'emplacement indiqué par sa Destination. Si la copie échoue (fichier introuvable), rien n'est enregistré et le message indique le fichier en cause.

Grille « Lancements » (LaunchCommands)

Programmes ou scripts à démarrer avec DCS.

ChampSignification
CommandChemin de l'exécutable ou du script. Bouton … (filtre *.exe).
runtimeTagQuand lancer : all (toujours), 2D (uniquement au démarrage 2D), VR (uniquement en VR). Les valeurs déjà présentes dans le fichier sont proposées en plus.
Répertoire de travailDossier de démarrage du programme (panneau Détails, bouton Parcourir).
Param 1 à 9Arguments passés au programme (panneau Détails).
needAdminRightsAttribut du fichier XML : exécute le programme avec élévation de privilèges.
Exemples de lancements courants

DCS-SRS (client radio), SimApp Pro (Winwing), VoiceAttack, un script .bat qui bascule une sortie audio, l'application de son cockpit, etc. Mettez runtimeTag = VR sur ce qui n'a de sens qu'en réalité virtuelle.

Onglet « Écrans »

Voir la page dédiée Gestion des écrans. En résumé : grille des écrans (index, deviceName, HwId, primary, orientation, largeur, hauteur, position X/Y) et bouton Import moniteurs qui récupère la géométrie des affichages Windows. LITE ces valeurs sont enregistrées mais non appliquées ; PRO elles pilotent la disposition du bureau.

Onglet « Helios »

  • Case « actif » : si décochée, aucun bloc Helios n'est enregistré pour le profil.
  • runtimeTag : mode dans lequel Helios est lancé : all (ou vide) dans les deux cas, 2D ou VR selon le bouton.
  • Dossier de profils : répertoire des profils Helios (bouton Parcourir).
  • Control Center : exécutable de Helios Control Center, nommé Control Center.exe dans le dossier d'installation de Helios.
  • Fichier de profil : profil .hpf à ouvrir. Il est enregistré relativement au dossier de profils (un chemin complet reste accepté). Sans profil, Control Center est lancé seul.

Au clic sur VR ou 2D, Control Center est démarré avec ce profil si la case « actif » est cochée. À l'enregistrement, l'éditeur vous prévient si Control Center ou le profil est introuvable.

Onglet « Mods associés »

Liste à cases à cocher des mods détectés dans le dossier de mods. Cochez ceux qui doivent être actifs pour ce profil. À la sélection du profil dans la fenêtre principale, l'application planifie l'activation des mods cochés manquants et la désactivation des mods actifs non cochés (en tenant compte des incompatibilités déclarées). Voir Gestion des mods.

Valider et enregistrer

BoutonAction
ValiderApplique le panneau courant, supprime les lignes vides et contrôle le modèle par rapport au schéma config-ecrans.xsd. N'écrit rien. Affiche la liste des erreurs le cas échéant.
SaveValide puis écrit config-ecrans.xml (copie .bak horodatée de l'ancien), crée et initialise les sous-dossiers des nouveaux profils. Au premier lancement, génère aussi le bloc <dcs> et vérifie les exécutables DCS.
FermerAbandonne les modifications. Si des changements sont en attente, une confirmation est demandée.
Configuration non conforme

Si la validation échoue, rien n'est enregistré. La boîte d'erreurs peut être copiée dans le presse-papiers pour analyse. Corrigez les points signalés (souvent un chemin obligatoire vide ou un attribut manquant sur un écran) puis réessayez.
