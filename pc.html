Préparer le PC pour DCS

Le bouton PC… de la barre d'outils ouvre la fenêtre Préparer le PC pour DCS. Elle passe en revue ce qui peut freiner DCS sur votre ordinateur : réglages de Windows, antivirus, programmes ouverts, mémoire de la carte graphique. Lancez-la juste avant de voler, avec vos programmes habituels ouverts.

Rien n'est modifié sans votre accord

L'analyse ne fait que lire. Chaque bouton d'action demande confirmation avant de changer quoi que ce soit, et config-ecrans.xml est toujours sauvegardé (copie .bak) avant d'être modifié.

Lire la liste

Chaque ligne a trois colonnes :

  • État : OK (vert, rien à faire), À voir (orange, une amélioration est possible) ou Info (à savoir, sans urgence).
  • Réglage : le nom commence par l'endroit où se trouve ce réglage, pour savoir où aller le changer :
    • Windows : un réglage de Windows lui-même (application Paramètres ou Sécurité Windows) ;
    • Antivirus : un réglage à faire dans votre antivirus (Bitdefender, Norton…) ;
    • Logiciel Process Lasso, Programmes ouverts :, Carte graphique : : un programme installé ou en cours d'exécution ;
    • VisualPosiScreen : une option de VisualPosiScreen.
  • Constat : ce qui a été trouvé, par exemple « Mode Jeu de Windows activé ».

Cliquez sur une ligne : le conseil détaillé s'affiche en dessous, avec les boutons utiles pour ce point.

Deux « modes jeu » différents

Windows : Mode Jeu est le réglage de Windows (Paramètres > Jeux > Mode Jeu). Le mode jeu de l'antivirus (par exemple le profil Jeu de Bitdefender) est un autre réglage, dans l'antivirus lui-même. Les deux sont utiles et indépendants : l'un ne remplace pas l'autre.

Les boutons

  • Ouvrir les paramètres Windows : ouvre directement la bonne page de Windows pour le point choisi. Pour l'antivirus, le bouton devient Ouvrir Bitdefender (ou le nom de votre antivirus).
  • Activer l'option Hyper-V : voir Hyper-V.
  • PRO Ajouter au profil de session : les programmes trouvés seront fermés avant DCS et relancés après le vol.
  • PRO Appliquer à Process Lasso : ajoute les règles conseillées (vos règles actuelles ne changent pas ; droits administrateur demandés).
  • PRO Ajouter les exclusions Defender : voir Antivirus.
  • Copier le rapport : copie toute l'analyse, à coller dans une demande d'aide.

Antivirus

L'analyse en temps réel de l'antivirus contrôle chaque fichier que DCS ouvre : les missions mettent plus longtemps à charger et des saccades peuvent apparaître. Une analyse ou une mise à jour lancée en plein vol coûte aussi du disque et du processeur. Deux réglages règlent ça, dans l'antivirus :

  1. Des exceptions : le dossier d'installation de DCS et son dossier Saved Games\DCS ne sont plus analysés à chaque ouverture. La fenêtre affiche les chemins exacts de votre PC.
  2. Le mode jeu de l'antivirus : il reporte analyses, mises à jour et notifications à la fin du vol. Il ne supprime pas les mises à jour : ne les coupez jamais, un antivirus qui n'est plus à jour ne protège plus.

La fenêtre détecte l'antivirus actif et donne la marche à suivre pour Bitdefender, Norton, Kaspersky, Avast/AVG, ESET et McAfee (les menus peuvent varier un peu selon la version de l'antivirus).

Exemple : Bitdefender

  1. Protection > Antivirus > Paramètres > Gérer les exceptions > Ajouter une exception : ajouter les deux dossiers, en cochant l'antivirus et Advanced Threat Defense.
  2. Utilitaires > Profils > Profil Jeu > Configurer : ajouter DCS.exe à la liste des jeux. Le profil s'active alors tout seul au lancement de DCS.
Pourquoi VisualPosiScreen ne le fait pas lui-même

Les antivirus du commerce n'offrent aucun moyen à un autre programme de changer leurs réglages, et leur autoprotection l'empêche. L'élément reste donc en Info : réglage à faire dans l'antivirus, même une fois le réglage fait.

Microsoft Defender

Avec l'antivirus de Windows, la fenêtre vérifie les exclusions déjà en place. Windows les cache aux comptes sans droits administrateur : dans ce cas, le constat l'indique. PRO le bouton Ajouter les exclusions Defender les ajoute pour vous (droits administrateur demandés, vos exclusions actuelles restent). Sinon : Sécurité Windows > Protection contre les virus et menaces > Gérer les paramètres > Exclusions. N'installez dans ces dossiers que des mods de source sûre.

Hyper-V pendant le vol

Hyper-V (utilisé par WSL, Docker, les machines virtuelles et l'isolation du noyau) coûte des performances à DCS. L'option Hyper-V de VisualPosiScreen le coupe seulement le temps du vol :

  1. Au lancement de DCS, si Hyper-V tourne, l'application propose de le couper (droits administrateur), puis il faut redémarrer le PC et relancer DCS.
  2. À la fin du vol, Hyper-V est réactivé pour le démarrage suivant, et un son le signale.

Activez-la avec le bouton Activer l'option Hyper-V de la fenêtre PC…, ou dans config-ecrans.xml (voir la référence). Si l'intégrité de la mémoire est active dans Windows, elle relance Hyper-V à chaque démarrage : il faut alors la désactiver (Sécurité Windows > Sécurité de l'appareil > Isolation du noyau).

PRO Profil de session DCS

Le profil de session prépare le PC à chaque lancement de DCS, puis remet tout en place à la fin du vol :

  • avant DCS : fermer les programmes choisis (navigateurs, OneDrive, Docker…), lancer des commandes (par exemple wsl --shutdown), passer sur un plan d'alimentation de performance, arrêter des services Windows, placer DCS sur les cœurs performants du processeur ;
  • à la fin de DCS : relancer les programmes avec leurs arguments d'origine, redémarrer les services, rétablir le plan d'alimentation.

Le plus simple est de le remplir depuis la fenêtre PC… : sélectionnez un point À voir puis Ajouter au profil de session. Windows, DCS, la VR, SRS, TrackIR, Stream Deck, TeamSpeak, Mumble et les programmes lancés par votre profil ne sont jamais fermés.

Si le PC redémarre juste après le vol, le plan d'alimentation et Hyper-V sont remis avant l'arrêt ; une session interrompue est rattrapée au démarrage suivant de VisualPosiScreen. Détail des balises : référence <session>.
