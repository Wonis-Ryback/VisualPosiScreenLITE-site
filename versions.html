Suivi des versions

Cette page présente l'historique des versions publiées de VisualPosiScreen LITE et explique comment l'application vous prévient lorsqu'une nouvelle version est disponible. Les versions sont publiées sur la page Releases du dépôt GitHub.

Connaître la version installée

Le numéro de version s'affiche dans l'indicateur de mise à jour de la barre d'outils de la fenêtre principale, ainsi que dans la fenêtre À Propos…. Il comporte quatre nombres (par exemple 3.3.4.1) : un numéro plus grand désigne toujours une version plus récente.

Mises à jour automatiques

À partir de quelle version ?

La vérification automatique est intégrée à partir de la 3.3.0.1. Si vous utilisez la 3.2.0.1 ou une version antérieure, téléchargez une première fois la dernière version depuis la page Installation : les suivantes seront ensuite proposées directement par l'application.

Au lancement

Chaque démarrage, l'application interroge en arrière-plan la page des versions de GitHub. Cette vérification ne bloque pas l'ouverture de la fenêtre et échoue silencieusement si vous n'avez pas de connexion (l'application reste pleinement utilisable). Si une version plus récente existe, une boîte de dialogue s'ouvre et affiche le numéro de la nouvelle version, sa date et ses nouveautés.

L'indicateur de la barre d'outils

À gauche du bouton À Propos…, un petit indicateur affiche en permanence l'état de votre installation :

AffichageSignificationUn clic…
✔ À jour (3.3.4.1)Vous utilisez la dernière version publiée.relance la vérification.
⬆ Mettre à jour (3.4.0.1)Une version plus récente est disponible (ici, à titre d'exemple, la 3.4.0.1).ouvre la boîte de dialogue de mise à jour.
Mise à jour : vérification impossiblePas d'accès à GitHub (réseau coupé, pare-feu, limite d'appels atteinte). Le message d'erreur détaillé figure dans l'info-bulle.réessaie la vérification.

Si vous choisissez Plus tard dans la boîte de dialogue, l'indicateur reste sur « Mettre à jour » jusqu'à ce que vous installiez la version. La boîte de dialogue est de nouveau proposée au prochain lancement.

Télécharger et installer

Le bouton Télécharger et installer enchaîne les étapes suivantes :

  1. Téléchargement de l'archive de la version depuis la page GitHub officielle, avec une barre de progression (le bouton Annuler interrompt l'opération).
  2. Vérification d'intégrité : l'empreinte SHA-256 du fichier téléchargé est comparée à celle publiée par GitHub. Si elle diffère, le fichier est rejeté et rien n'est installé.
  3. Décompression dans un dossier temporaire.
  4. Fermeture de l'application, remplacement des fichiers de son dossier par ceux de la nouvelle version, puis redémarrage automatique avec les mêmes arguments (par exemple le fichier config-ecrans.xml passé en ligne de commande).
Vos données sont conservées

Seuls les fichiers de l'application sont remplacés. Votre config-ecrans.xml, vos configurations, vos mods et vos fichiers DCS ne sont ni modifiés ni supprimés. Le déroulement est consigné dans le fichier update.log du dossier temporaire %TEMP%\VisualPosiScreenLITE-update.

Quand l'installation automatique n'est pas possible

  • Le dossier de l'application n'est pas modifiable (par exemple sous C:\Program Files\) : l'application ouvre la page de téléchargement dans votre navigateur. Décompressez alors l'archive dans un dossier où vous avez les droits d'écriture (voir Installation).
  • Échec du téléchargement, de la vérification ou de la copie : un message le signale et propose d'ouvrir la page de téléchargement pour une installation manuelle. L'ancienne version reste en place et fonctionnelle.

Historique détaillé

Version 3.3.4.1 Dernière

Publiée le 19 septembre 2026

  • Nouveau : bouton Écrans… dans la barre d'outils. La fenêtre affiche, à l'échelle et côte à côte, la disposition actuelle des écrans Windows et celle déclarée dans la configuration choisie, avec un code de couleurs (conforme, différent, affichage non déclaré, écran introuvable), l'écran principal et l'orientation. « Actualiser » relit le bureau et « Identifier les écrans » affiche le numéro de chaque écran sur cet écran. Voir Gestion des écrans.
  • Amélioration : le bouton « Import moniteurs » de l'éditeur renseigne désormais aussi l'identifiant HwId de chaque écran (sans écraser un HwId saisi à la main), son orientation et l'écran principal. Il n'est plus nécessaire de saisir le HwId manuellement.
  • Documentation : la page « Gestion des écrans » décrit la nouvelle fenêtre et présente le fonctionnement de l'application de la disposition d'écrans de l'édition PRO.

Version 3.3.3.1

Publiée le 18 septembre 2026

Correctif de la configuration moniteur de DCS. Mise à jour recommandée si vous avez créé des configurations avec une version 3.1 à 3.3.2.

  • Correction : à la création d'une configuration, le nom du fichier moniteur lu dans Options.lua (multiMonitorSetup, que DCS écrit sans extension) est désormais complété par .lua. Auparavant la zone de texte restait sans extension et le fichier n'était jamais copié dans le dossier de la configuration.
  • Correction : au lancement, le fichier moniteur est copié dans Config\MonitorSetup\<nom>.lua (le nom référencé par l'Options.lua de la configuration), là où DCS le lit. Il était copié dans Config\, sans effet.
  • Configurations existantes : le nom est affiché avec son extension ; à l'enregistrement dans l'éditeur, le fichier moniteur manquant dans le dossier d'une configuration est complété (sans jamais rien écraser), et le lancement accepte l'ancien nom sans extension. Voir Les configurations.

Version 3.3.2.1

Publiée le 18 septembre 2026

  • Correction : Helios n'était jamais lancé. Si la configuration a un bloc Helios actif dont le runtimeTag correspond au mode (all, 2D ou VR), Control Center est désormais démarré avec le profil indiqué, au clic sur VR ou 2D. Voir Lancer DCS World.
  • Correction : le démarrage de DCS est sécurisé. Le chemin de dcs.exe est vérifié avant toute action (si DCS a été déplacé, un message l'indique et rien n'est modifié), l'absence de profil 2D/VR, un <params> manquant et un refus des droits administrateur sont gérés, et l'application reste ouverte en cas d'échec pour permettre de corriger et de réessayer.
  • Correction : dans l'éditeur, le profil Helios choisi avec « Parcourir » est enregistré relativement au dossier de profils, comme l'attend le fichier de configuration.
  • Nouveau : à l'enregistrement, l'éditeur prévient si Control Center ou le profil Helios est introuvable. Voir L'éditeur de configuration.
  • Documentation : l'exécutable de Helios s'appelle Control Center.exe (et non ControlCenter.exe).

Version 3.3.1.1

Publiée le 18 septembre 2026

Version corrective du lancement de DCS. Mise à jour recommandée, en particulier pour les utilisateurs de la VR.

  • Correction : en VR, le fichier options.lua, la configuration moniteur et le script d'export de la configuration n'étaient jamais copiés avant le démarrage de DCS. Ils le sont désormais, comme en 2D.
  • Correction : en 2D, DCS démarrait avant la copie des fichiers de configuration, et les fichiers DCS ainsi que les programmes compagnons étaient exécutés deux fois. Toute la préparation se fait maintenant avant le démarrage de DCS, et une seule fois.
  • Correction : l'attribut runtimeTag des lancements est enfin pris en compte (all, 2D ou VR) : un programme marqué VR ne démarre plus en 2D, et inversement.
  • Correction : sans configuration sélectionnée, un message s'affiche au lieu d'une erreur.
  • Modification : si la préparation signale une erreur (fichier introuvable, programme qui ne démarre pas…), une boîte de dialogue propose de continuer ou d'abandonner le démarrage de DCS. Voir Lancer DCS World.

Version 3.3.0.1

Publiée le 18 septembre 2026

  • Nouveau : vérification automatique des mises à jour au démarrage, à partir des releases GitHub. Une boîte de dialogue propose de télécharger et d'installer la nouvelle version (contrôle d'intégrité SHA-256, remplacement des fichiers puis redémarrage automatique).
  • Nouveau : indicateur ✔ À jour / ⬆ Mettre à jour dans la barre d'outils de la fenêtre principale. Voir La fenêtre principale.
  • Nouveau : cette page de suivi des versions.
  • Correction : le numéro de version de l'application est désormais correct (il apparaissait sous la forme 0.0.0.x dans les versions précédentes).

Version 3.2.0.1

Publiée le 17 septembre 2026

  • Nouveau : catalogue d'applications tierces courantes pour DCS (TeamSpeak 3, DCS-SRS, SimApp Pro, VoiceAttack, TrackIR, opentrack, OpenKneeboard). Un bouton Catalogue… dans l'édition d'une configuration pré-remplit un lancement à partir de ces applications, avec détection automatique « au mieux » (chemins d'installation connus et registre Windows). Voir L'éditeur de configuration.
  • Correction : la sélection de la configuration se place désormais sur la première configuration disponible lorsqu'il n'y a pas eu de lancement précédent, ou lorsque la dernière configuration utilisée n'existe plus.

Version 3.1.0.1

Publiée le 17 septembre 2026

  • Correction : le répertoire des mods est désormais créé à l'installation (il était absent sur une installation vierge).
  • Nouveau : écran d'ajout de mod, avec choix des dossiers Root et Saved Games, y compris directement à l'intérieur d'une archive ZIP. Voir Gestion des mods.
  • Nouveau : écran d'édition des exclusions Trk⇒miz. Voir Outils intégrés.
  • Nouveau : le fichier de configuration moniteur d'une nouvelle configuration est détecté automatiquement depuis Options.lua (paramètre multiMonitorSetup) et copié depuis Saved Games ou depuis l'installation de DCS.
  • Modification : le dossier Scripts est retiré des exclusions Trk⇒miz par défaut.

Version 3.0.0.1

Publiée le 16 septembre 2026

  • Première version publiée : build autonome pour Windows 10/11 x64, sans aucun prérequis à installer.
  • Guide utilisateur complet (cette documentation).
